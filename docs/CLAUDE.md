# Docs

`docs/` holds the durable decisions (architecture, workflow, schema,
integrations); `README.md` here is the topic index.

- Maintaining these documents is not required when shipping runtime changes.
  When you do edit one: mechanical facts (schema columns, endpoint lists,
  module inventories, code-flow narration) live in the code — keep them out
  of docs — and date externally observed facts, citing the source.
